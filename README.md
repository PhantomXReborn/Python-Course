# Complete Python Course: From Print to Recursion

A structured Python curriculum guiding beginners from print statements to advanced topics including recursion, file manipulation, and logic. Each lesson follows a proven learning pattern.

## Course Structure

The course contains 14 core modules. Each module has 12 lessons. Every lesson includes:
- 3 Predict & Run exercises (read code, predict output, then run)
- 3 Investigate activities (analyze how code works)
- 3 Modify tasks (change existing code to alter behavior)
- 3 Make challenges (write original code from scratch)

## Core Modules (14 modules x 12 lessons)

Module 1: Print Statements & Basic Output
Module 2: Variables & Data Types
Module 3: String Manipulation
Module 4: Numeric Operations & Math
Module 5: Conditional Statements (if/elif/else)
Module 6: Loops (for and while)
Module 7: Lists and Tuples
Module 8: Dictionaries and Sets
Module 9: Functions and Scope
Module 10: Error Handling (try/except)
Module 11: File Reading
Module 12: File Writing and Appending
Module 13: Recursion Basics
Module 14: Advanced Recursion (tree traversal, backtracking)

## Capstone Project Modules (4 modules)

After completing the 14 core modules, learners build four complete projects:

Project 1: Cryptography Project
- Caesar cipher implementation
- File encryption/decryption
- Password hashing demonstration
- Symmetric key simulation

Project 2: Recursion Project
- Factorial and Fibonacci solvers
- Directory tree walker
- Maze solver using backtracking
- Fractal pattern generator

Project 3: File Manipulation Project
- CSV and JSON processor
- Log file analyzer
- File organizer/sorter utility
- Data backup and merge tool

Project 4: Logic Project
- Truth table generator
- Boolean expression simplifier
- Propositional logic evaluator
- Simple theorem checker

## Total Course Breakdown

- 14 modules x 12 lessons = 168 lessons
- Each lesson: 12 exercises (3+3+3+3)
- Total exercises: 2,016
- Plus 4 large projects

## Prerequisites

- No prior programming experience needed
- Computer with Python 3.6 or higher
- Any text editor (VS Code, Notepad++, IDLE, or Thonny)

## Getting Started

1. Install Python from python.org
2. Download or clone this repository
3. Start with Module 1, Lesson 1
4. Complete all 12 exercises per lesson before moving forward

## Lesson Template Example

For each lesson, the pattern is:

Predict & Run (3):
- Given code snippets, write predicted output
- Run actual code and compare

Investigate (3):
- Explain what each line does
- Identify variable changes
- Trace function calls

Modify (3):
- Change values and observe results
- Add new features to existing code
- Fix intentional bugs

Make (3):
- Write code from requirements
- Create small programs
- Solve mini challenges

## Progress Tracking

Suggested pace:
- Beginner: 1 lesson per day (168 days total)
- Intermediate: 2-3 lessons per day (8-12 weeks)
- Intensive: 5 lessons per day (5-6 weeks)

## Assessment

- Complete all Predict & Run exercises before moving on
- Submit Investigate answers as comments
- Save all Modify and Make code in your workspace
- Final evaluation based on four capstone projects

## Project Submission

Each capstone project requires:
- Working Python code
- Documentation of approach
- Test cases and outputs
- Reflection on learning
