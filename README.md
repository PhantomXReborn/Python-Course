# Complete Python Course: From Print to Recursion

A structured Python curriculum that guides learners from fundamental print statements to advanced topics including recursion and file manipulation.

## Course Overview

This course covers:
- Print statements and basic syntax
- Variables and data types
- Conditional statements and loops
- Functions and scope
- File input/output operations
- Recursion and problem-solving

## Prerequisites

- No prior programming experience required
- A computer with Python 3.x installed
- A text editor or IDE (VS Code, PyCharm, or IDLE)

## Course Structure

Each module includes:
- Conceptual explanations
- Code examples
- Hands-on exercises
- Mini-projects

## Getting Started

1. Install Python from python.org
2. Clone or download this repository
3. Navigate to each module folder
4. Run examples using: `python filename.py`

## Modules

1. **Module 1:** Print Statements & Basic Output
2. **Module 2:** Variables & Data Types
3. **Module 3:** Control Flow (if/else, loops)
4. **Module 4:** Functions & Scope
5. **Module 5:** File Manipulation (read/write)
6. **Module 6:** Recursion Fundamentals

## Projects

- Calculator application
- File text analyzer
- Recursive directory tree printer
- Data formatter using file I/O
